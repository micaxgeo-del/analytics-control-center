# Analytics Control Center

Dashboard interactivo desarrollado como proyecto de portafolio para demostrar habilidades en análisis de datos, visualización y desarrollo de dashboards web.

## Objetivo

Crear una interfaz moderna e interactiva para el monitoreo de métricas de negocio, permitiendo visualizar indicadores clave de rendimiento (KPIs), tráfico, audiencias, conversiones y ventas en tiempo real.

## Características

* Dashboard ejecutivo interactivo.
* KPIs de negocio y rendimiento.
* Análisis de tráfico y audiencia.
* Visualización de dispositivos utilizados por los usuarios.
* Embudo de conversión.
* Distribución geográfica de visitantes.
* Registro de actividad y eventos en tiempo real.
* Exportación de datos a Excel/CSV.
* Diseño responsive para escritorio y dispositivos móviles.

## Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript (ES6)
* Chart.js
* GitHub Pages
* Netlify

## Habilidades Demostradas

* Data Visualization
* Business Intelligence

* Dashboard Design
* Front-End Development
* Data Analytics

Este dashboard fue desarrollado con fines demostrativos para representar un entorno de análisis empresarial y monitoreo de métricas clave.
